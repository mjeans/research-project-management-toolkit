# Definition of done

A work item is complete when all applicable criteria below are satisfied.

## Analytic work

- inputs come from the approved, versioned source
- inclusion and exclusion logic is documented
- code runs from a clean environment or documented starting state
- expected row counts and key summaries are checked
- assumptions and diagnostics are reviewed
- outputs do not expose restricted or unnecessary row-level information
- another reviewer can understand the purpose and reproduce the result
- deviations from the approved plan are logged

## Deliverables

- content answers the approved evaluation question
- estimates, denominators, time periods, and populations are labeled
- uncertainty and limitations are visible
- technical and nontechnical versions do not contradict one another
- accessibility and formatting requirements are met
- comments are resolved or dispositioned
- the named approver has accepted the deliverable

## Project controls

- requirement status and acceptance evidence are current
- linked risks, issues, decisions, and changes are updated
- dates and dependencies reflect the latest approved baseline
- owner and next action are clear
- final artifact location and version are recorded
